# Essence Network V3 — GitHub/Render layout

This archive is flattened for direct upload to the root of the GitHub repository.

Required structure:
- `package.json`
- `public/index.html`
- `public/app.js`
- `public/style.css`
- `server/server.js`
- `server/db.js`
- `server/auth.js`
- `server/init-admin.js`
- `data/`
- `uploads/`

Render:
- Build command: `npm install`
- Start command: `npm start`
- Node: `>=20`
- Set `JWT_SECRET` in Render Environment.
